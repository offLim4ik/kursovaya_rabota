# Вектор — образовательная платформа

Полноценное локальное веб-приложение для управления курсами, последовательного обучения и учёта результатов. Интерфейс на русском языке. Основано на существующем Flask-проекте.

## Стек и архитектура

- Python 3.13, Flask 3.1, Werkzeug: HTTP API, сессии и scrypt-хеширование паролей.
- SQLite: нормализованные таблицы, внешние ключи, уникальные ограничения, SQL-миграции и транзакции BEGIN IMMEDIATE.
- HTML, CSS, JavaScript без frontend-зависимостей и CDN: клиентская маршрутизация, формы и загрузка данных через Fetch API.
- Bleach: очистка форматированного HTML; Pillow: проверка и повторное кодирование изображений.
- ReportLab: PDF-сертификаты со встроенным Unicode-шрифтом.
- Waitress: production WSGI-сервер, совместимый с Windows.
- Pytest, Ruff, Mypy: интеграционные тесты, линтер и базовая статическая проверка Python.

Frontend и API работают с одного origin. Пользователи, курсы, прогресс, попытки, заметки и сертификаты хранятся в SQLite. В sessionStorage находится только адрес возврата после входа, учебные данные туда не записываются.

## Установка и первый запуск в PowerShell

Из корня проекта:

```powershell
py -3.13 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe scripts/prepare_local.py
.venv/Scripts/python.exe -m flask --app app init-db
.venv/Scripts/python.exe -m flask --app app create-admin --email admin@example.test --name "Администратор"
.venv/Scripts/python.exe -m waitress --host=127.0.0.1 --port=5000 app:app
```

Откройте http://127.0.0.1:5000. Пароль администратора команда запрашивает скрыто, с повторным вводом; он должен содержать 10–128 символов. Администраторы создаются только этой локальной командой, без регистрации роли через API. Существующий пользователь командой не повышается в правах.

`prepare_local.py` создаёт `.env` со случайным секретом, только если файл ещё не существует. Он также создаёт шесть локальных SVG-обложек. Никакие ключи не печатаются. Вместо команды можно скопировать `.env.example` в `.env` и самостоятельно задать `SECRET_KEY`.

Для разработки можно запускать `python app.py` через виртуальное окружение; debug по умолчанию выключен. На Linux используйте `.venv/bin/python` и настройте `PDF_FONT`, если DejaVu Sans отсутствует.

## Демонстрационные данные — отдельный шаг

После миграций, до добавления собственных курсов:

```powershell
.venv/Scripts/python.exe -m flask --app app seed-demo
```

Чтобы расширить уже существующие демонстрационные курсы новыми модулями, практикой и тестами, выполните:

```powershell
.venv/Scripts/python.exe -m flask --app app upgrade-demo
```

Команда добавляет тематический модуль к каждому из шести базовых курсов и проверочные задания с несколькими типами ответов. Она безопасна при повторном запуске и сохраняет записи, прогресс и сертификаты. Новые уроки входят в обязательную программу; уже завершённые учебные записи остаются завершёнными и сертификаты сохраняют исходное состояние. Тему можно настроить в редакторе курса.

Команда заполняет только базу без курсов, не очищает её и отказывается повторно создавать демонстрацию. Она добавляет:

- 6 содержательных курсов: Python, дизайн интерфейсов, SQL, тестирование, менеджмент проектов, безопасность.
- Курс Python с 3 модулями, 6 уроками и 2 тестами, включая вопросы с несколькими ответами.
- `demo1@example.test`, `demo2@example.test`, `demo3@example.test` с разным прогрессом.
- Попытки, события, уведомления, завершения, сертификаты и отзывы.

Случайный временный пароль демонстрационных аккаунтов выводится один раз командой. Они не имеют административных прав. Администратор не входит в демонстрационные данные.

## Основные сценарии

Каталог доступен без входа: поиск по названию и описанию, направление, уровень, статус записи, избранное, сортировка, страницы по 6 курсов. Страница курса показывает программу, результаты, требования, длительность, участников и отзывы.

Пользователь регистрируется, записывается и проходит уроки последовательно. Открытие урока фиксирует начало, но не завершение. Обычный урок завершается кнопкой, урок с тестом — только после серверной проверки. Повторное завершение не начисляет прогресс повторно. После повторного входа кабинет предлагает последний незавершённый доступный урок.

В кабинете доступны статистика, курсы в процессе и завершённые, история, уведомления и сертификаты. В профиле — имя, загрузка аватара и смена пароля с проверкой текущего. Заметки к урокам приватны. Отзыв доступен только после завершения курса.

Администратор использует `/admin`: обзор, курсы, пользователи, аналитика, журнал. Редактор позволяет добавлять и переставлять модули и уроки, вводить безопасный HTML, разрешённое видео, загружать материалы, создавать вопросы, варианты, правильные ответы, пояснения и проходной балл. Предпросмотр использует сохранённый очищенный материал. Перед уходом при несохранённых изменениях появляется подтверждение.

В настройках программы доступен выбор темпа: последовательный (урок открывается после предыдущего) или свободный (все уроки доступны сразу после записи). Изменение не удаляет данные прогресса и применяется к последующим открытиям уроков.

Публикация проверяет категорию, описание, результаты обучения, непустые модули, содержимое уроков и корректность тестов. Архивирование скрывает курс из каталога, сохраняя доступ ранее записанным участникам. Статистика строится по таблицам базы; график доступен также в табличном виде.

## Правила прогресса и изменений

Все уроки в этой версии обязательные. Прогресс рассчитывается сервером: число завершённых уроков / общее число уроков. Для завершённой записи результат остаётся 100%.

До первой записи на курс разрешены изменения состава уроков и тестов. После первой записи:

- Идентификаторы уроков сохраняются при переименовании, редактировании содержания и перестановке.
- Добавление и удаление уроков запрещены сервером. Для новой программы создаётся новый курс; автоматического переноса результатов между версиями нет.
- Вопросы, варианты, пояснения и проходной балл тестов зафиксированы, чтобы история попыток сохраняла смысл.
- Перестановка не отменяет завершённые уроки. Они всегда доступны; новые доступные шаги определяются текущим порядком.
- Уже завершённый курс и сертификат остаются завершёнными. Сертификат хранит снимок имени, названия и даты выдачи.
- Архивирование используется вместо удаления курсов. Возврат из архива возможен через редактор после проверки публикации.

## Безопасность и хранение

- Серверная роль только `user` или `admin`; регистрация игнорирует клиентское поле role.
- Сессионная cookie подписана, HttpOnly, SameSite=Lax, срок 14 дней. При блокировке и смене пароля меняется session_version; доступ проверяется на каждом запросе.
- CSRF-токен обязателен для изменяющих операций. Токен обновляется при входе.
- Параметризованные SQL-запросы. Изменения выполняются в транзакции, UNIQUE защищает записи, прогресс, отзывы, сертификаты и избранное от дублей.
- Ограничение регистрации/входа: 15 запросов с одного IP за 15 минут; счётчики хранятся в базе. Заголовкам X-Forwarded-For приложение не доверяет.
- Учебные файлы отдаются после проверки записи и доступности урока. Чужие сертификаты, заметки, попытки и прогресс не выдаются.
- Загрузка до 8 МБ, HTTP-запрос до 10 МБ. Изображения: JPG/PNG/WebP до 16 мегапикселей, декодирование и повторное сохранение в JPEG. Материалы: также PDF, UTF-8 TXT/CSV. Имена на диске случайные, PDF и текст выдаются вложениями.
- Обложки и аватары публичны. SVG принимаются только как встроенные иллюстрации из исходного проекта; загружать SVG нельзя.
- Разрешённые iframe: `https://www.youtube-nocookie.com/embed/ID`, `https://rutube.ru/play/embed/ID/`. Приложение не загружает произвольные URL сервером.
- CSP, X-Frame-Options, nosniff, запрет кеширования API. Ошибки пользователю не раскрывают внутренний traceback.
- Важные административные операции пишутся в журнал. Последний активный администратор защищён от блокировки.

В production задайте собственный `SECRET_KEY`, HTTPS и `COOKIE_SECURE=1`; запускайте Waitress за настроенным HTTPS reverse proxy. SQLite и `instance/uploads` требуют резервного копирования вместе. Не публикуйте `.env`, `instance`, `.venv` и файлы локального доступа.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| SECRET_KEY | Случайный секрет подписи сессий; без него HTTP отвечает 503 |
| DATABASE | Путь к SQLite, по умолчанию instance/platform.sqlite3 |
| COOKIE_SECURE | 1 при HTTPS, 0 для локального HTTP |
| PDF_FONT | Путь к TTF с кириллицей; автоматически Arial в Windows или DejaVu Sans в Linux |

## Проверки и production-пакет

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check .
.venv/Scripts/python.exe -m mypy
node --check static/app.js
.venv/Scripts/python.exe scripts/build.py
```

Frontend не требует транспиляции. Production-проверка компилирует Python и создаёт `dist/vector-platform.zip`, `dist/manifest.json` с SHA-256 каждого файла и `dist/SOURCE_CODE.md` с полным содержимым исходников. В пакет не входят секреты, база, загруженные файлы и виртуальное окружение. Архив нужно распаковать, установить зависимости и выполнить настройку из инструкции выше.

## Известные ограничения

- Это готовое локальное приложение для небольших учебных групп, не проверенный нагрузочными испытаниями многопользовательский SaaS. SQLite сериализует записи; каталог и административные списки пока не оптимизированы для десятков тысяч записей.
- Внешние видео не сохраняют временную позицию; последний доступный урок сохраняется. Воспроизведение зависит от доступности разрешённого провайдера.
- Форматированный контент редактируется как безопасный HTML, без визуального WYSIWYG-редактора. Изображения добавляются материалами урока.
- Нет внешних интеграций, оплаты, чата, подтверждения email и восстановления пароля по email. Их не требует основной сценарий.
- Файлы проверяются по типу и содержимому, но не сканируются антивирусом. Неиспользуемые загруженные файлы автоматически не удаляются с диска.
- Журнал показывает последние 300 действий, кабинет — последние 100 событий и уведомлений; полная история остаётся в базе.
- Полная кроссбраузерная, нагрузочная и screen-reader сертификация не проводилась.
