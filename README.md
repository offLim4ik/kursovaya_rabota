# Вектор — образовательная платформа

Полноценное локальное веб-приложение для управления курсами, последовательного обучения и учёта результатов. Интерфейс на русском языке. Основано на существующем Flask-проекте.

## Стек и архитектура

- Python 3.13, Flask 3.1, Werkzeug: HTTP API, сессии и scrypt-хеширование паролей.
- SQLite: нормализованные таблицы, внешние ключи, уникальные ограничения, SQL-миграции и транзакции BEGIN IMMEDIATE.
- HTML, CSS, JavaScript без frontend-зависимостей и CDN: клиентская маршрутизация, формы и загрузка данных через Fetch API.
- Bleach: очистка форматированного HTML; Pillow: проверка и повторное кодирование изображений.
- ReportLab: PDF-сертификаты со встроенным Unicode-шрифтом.
- Waitress: production WSGI-сервер, совместимый с Windows.
- Pytest, Ruff, Mypy: интеграционные тесты, линтер и базовая статическая проверка Python.

Frontend и API работают с одного origin. Пользователи, курсы, прогресс, попытки, заметки и сертификаты хранятся в SQLite. В sessionStorage находится только адрес возврата после входа, учебные данные туда не записываются.

## Полный запуск с нуля

### Требования

- Python **3.13** и Git.
- Windows 10/11 с PowerShell или macOS/Linux с терминалом.
- Интернет для установки Python-пакетов при первом запуске.

Проверить Python можно командой `py -3.13 --version` в Windows или `python3.13 --version` в macOS/Linux. Если команды нет, установите Python 3.13 и включите добавление Python в PATH.

### 1. Скачать проект

Предпочтительный способ — клонировать репозиторий:

```powershell
git clone https://github.com/offLim4ik/kursovaya_rabota.git
cd kursovaya_rabota
```

Либо на GitHub нажмите **Code → Download ZIP**, распакуйте архив, откройте PowerShell в распакованной папке и перейдите в каталог проекта. Все дальнейшие команды выполняются из корня, где находятся `app.py` и `requirements.txt`.

### 2. Создать окружение и установить зависимости

В PowerShell:

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

В macOS/Linux:

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements-dev.txt
```

`requirements-dev.txt` устанавливает зависимости приложения и инструменты разработки. Для обычного запуска без тестов можно установить только `requirements.txt`.

### 3. Подготовить локальные файлы и базу

В PowerShell:

```powershell
.venv\Scripts\python.exe scripts\prepare_local.py
.venv\Scripts\python.exe -m flask --app app init-db
```

В macOS/Linux:

```bash
.venv/bin/python scripts/prepare_local.py
.venv/bin/python -m flask --app app init-db
```

Первый шаг создаёт `.env` со случайным `SECRET_KEY` и локальные обложки, если их ещё нет. Второй создаёт `instance/platform.sqlite3` и применяет SQL-миграции. Секреты и база остаются на компьютере и не попадают в GitHub.

### 4. Создать администратора

PowerShell:

```powershell
.venv\Scripts\python.exe -m flask --app app create-admin
```

macOS/Linux:

```bash
.venv/bin/python -m flask --app app create-admin
```

Команда запросит email, имя и пароль. Пароль вводится скрыто дважды, длина — 10–128 символов. Запомните его: приложение хранит только защищённый хеш, восстановить исходный пароль нельзя. Публичная регистрация создаёт только обычные аккаунты; повторный запуск команды не повышает права существующего пользователя.

Если пароль администратора утерян, сбросьте его локально; команда завершит его старые сессии и запросит новый пароль скрытым вводом.

```powershell
.venv\Scripts\python.exe -m flask --app app reset-admin-password --email admin@example.test
```

В macOS/Linux используйте `.venv/bin/python -m flask --app app reset-admin-password --email admin@example.test`. Укажите email существующего администратора вместо примера.

### 5. (Необязательно) Загрузить демонстрационные курсы

Чтобы заполнить пустую базу всеми подготовленными курсами, выполните команды по порядку.

PowerShell:

```powershell
.venv\Scripts\python.exe -m flask --app app seed-demo
.venv\Scripts\python.exe -m flask --app app upgrade-demo
.venv\Scripts\python.exe -m flask --app app enrich-demo
.venv\Scripts\python.exe -m flask --app app add-extra-courses
.venv\Scripts\python.exe -m flask --app app fill-course-library
```

macOS/Linux:

```bash
.venv/bin/python -m flask --app app seed-demo
.venv/bin/python -m flask --app app upgrade-demo
.venv/bin/python -m flask --app app enrich-demo
.venv/bin/python -m flask --app app add-extra-courses
.venv/bin/python -m flask --app app fill-course-library
```

В каталоге будет 18 опубликованных содержательных курсов по 12 уроков (216 уроков суммарно), с примерами, практикой, тестами и итоговыми заданиями. `fill-course-library` можно запускать повторно: он добавляет недостающие темы без создания дублей. Если в каталоге остались тестовые курсы «Новый курс» или «111111111111111», команда архивирует их, не удаляя записи, сертификаты и историю. `seed-demo` создаёт также три демонстрационных аккаунта обычных пользователей. Случайный временный пароль для них показывается в терминале один раз — сохраните его, если он нужен для показа. Эти данные не включают администратора: его вы создали на шаге 4.

Команда `seed-demo` рассчитана на базу без курсов и не удаляет существующие данные. Не запускайте её в базе с вашими курсами. Остальные команды добавляют содержимое без повторного создания уже добавленных элементов.

### 6. Запустить сайт

PowerShell:

```powershell
.venv\Scripts\python.exe -m waitress --host=127.0.0.1 --port=5000 app:app
```

macOS/Linux:

```bash
.venv/bin/python -m waitress --host=127.0.0.1 --port=5000 app:app
```

Откройте **http://127.0.0.1:5000**. Войдите под email и паролем администратора, созданными на шаге 4. Чтобы остановить сайт, вернитесь в окно терминала и нажмите `Ctrl+C`. Если порт 5000 занят, замените его, например, на `5001` и откройте `http://127.0.0.1:5001`.

### Запуск в следующие разы

Повторно клонировать проект, создавать окружение, администратора или демонстрационные данные не нужно. Из корня проекта запустите команду Waitress из шага 6. Курсы и прогресс сохраняются в `instance/platform.sqlite3`; перед переустановкой компьютера сохраните всю папку `instance` и `.env` в надёжное место.

### Проверки разработчика

```powershell
.venv\Scripts\python.exe -m pytest -q --basetemp=tmp\pytest
.venv\Scripts\ruff.exe check .
.venv\Scripts\mypy.exe
node --check static\app.js
.venv\Scripts\python.exe scripts\build.py
```

В Linux/macOS вместо `.venv\Scripts\...` используйте `.venv/bin/...`. Для установки проверок нужны пакеты из `requirements-dev.txt`.

## Основные сценарии

Каталог доступен без входа: поиск по названию и описанию, направление, уровень, статус записи, избранное, сортировка, страницы по 6 курсов. Страница курса показывает программу, результаты, требования, длительность, участников и отзывы.

Пользователь регистрируется, записывается и проходит уроки последовательно. Открытие урока фиксирует начало, но не завершение. Обычный урок завершается кнопкой, урок с тестом — только после серверной проверки. Повторное завершение не начисляет прогресс повторно. После повторного входа кабинет предлагает последний незавершённый доступный урок.

В кабинете доступны статистика, курсы в процессе и завершённые, история, уведомления и сертификаты. В профиле — имя, загрузка аватара и смена пароля с проверкой текущего. Заметки к урокам приватны. Отзыв доступен только после завершения курса.

Администратор использует `/admin`: обзор, курсы, пользователи, аналитика, журнал. Редактор позволяет добавлять и переставлять модули и уроки, вводить безопасный HTML, разрешённое видео, загружать материалы, создавать вопросы, варианты, правильные ответы, пояснения и проходной балл. Предпросмотр использует сохранённый очищенный материал. Перед уходом при несохранённых изменениях появляется подтверждение.

В настройках программы доступен выбор темпа: последовательный (урок открывается после предыдущего) или свободный (все уроки доступны сразу после записи). У каждого модуля настраиваются описание, ожидаемые результаты, порядок и дополнительное условие открытия после завершения выбранного предыдущего модуля. Уроки можно переносить между модулями и сами модули переставлять. Изменение сохраняет ID уроков и историю прогресса. В курсе с участниками уроки можно переносить, но добавлять и удалять их нельзя; завершённые результаты остаются закреплены за своими уроками.

Публикация проверяет категорию, описание, результаты обучения, непустые модули, содержимое уроков и корректность тестов. Архивирование скрывает курс из каталога, сохраняя доступ ранее записанным участникам. Статистика строится по таблицам базы; график доступен также в табличном виде.


### Практические работы и обратная связь

В редакторе урока добавляется задание с инструкциями, обязательностью, форматом ответа (текст, HTTPS-ссылка или закрытый файл PDF/TXT/CSV) и рубрикой критериев с баллами. Общий максимум равен сумме критериев. Принятая работа становится неизменяемой, а критерии блокируются с первой отправки, чтобы отзывы и оценки не менялись задним числом. Администратор проверяет очередь в `/admin/reviews`, выставляет баллы по критериям и пишет рекомендации. Обязательная работа открывает завершение урока после принятия; если урок также содержит тест, требуются оба условия. Работы и файлы не доступны другим ученикам.

### Версии опубликованных курсов

При сохранении опубликованного курса редактор фиксирует неизменяемый снимок содержимого, программы и тестов. В истории версий администратор может загрузить старый снимок в редактор и отдельно сохранить его как новую версию. Идентификаторы уроков сохраняются; прогресс, сертификаты и результаты попыток остаются привязаны к тем же урокам. Для курса с участниками добавление и удаление уроков по-прежнему запрещено; редактирование тестов при наличии записей зафиксировано, чтобы не менять условия после попыток.

### Цели и напоминания

Учащийся задаёт цель в минутах на неделю, время и включение напоминаний. Кабинет показывает плановую длительность открытых уроков за последние семь дней. Это оценка нагрузки по продолжительности уроков, не таймер реального времени. Напоминания — внутренние уведомления. Для автоматической доставки по расписанию добавьте ежедневную задачу `flask --app app send-learning-reminders` в планировщик ОС или cron; повторный вызов в тот же день не создаёт дубль.

### Аналитика

Раздел `/admin/analytics` дополняет регистрации, записи и популярность средним процентом прохождения курсов, попытками тестов, средним баллом и числом зачётов. Все значения вычисляются SQL-запросами по текущим таблицам платформы.

Сертификат использует альбомный формат, двойную рамку, темно-синюю бренд-плашку, аккуратные золотые акценты, печать, подпись платформы, имя, курс, дату и номер. Макет проверен рендером PDF в изображение.

## Правила прогресса и изменений

Все уроки в этой версии обязательные. Прогресс рассчитывается сервером: число завершённых уроков / общее число уроков. Для завершённой записи результат остаётся 100%.

До первой записи на курс разрешены изменения состава уроков и тестов. После первой записи:

- Идентификаторы уроков сохраняются при переименовании, редактировании содержания и перестановке.
- Добавление и удаление уроков запрещены сервером. Для новой программы создаётся новый курс; автоматического переноса результатов между версиями нет.
- Вопросы, варианты, пояснения и проходной балл тестов зафиксированы, чтобы история попыток сохраняла смысл.
- Перестановка не отменяет завершённые уроки. Они всегда доступны; новые доступные шаги определяются текущим порядком.
- Уже завершённый курс и сертификат остаются завершёнными. Сертификат хранит снимок имени, названия и даты выдачи.
- Архивирование используется вместо удаления курсов. Возврат из архива возможен через редактор после проверки публикации.

## Безопасность и хранение

- Серверная роль только `user` или `admin`; регистрация игнорирует клиентское поле role.
- Сессионная cookie подписана, HttpOnly, SameSite=Lax, срок 14 дней. При блокировке и смене пароля меняется session_version; доступ проверяется на каждом запросе.
- CSRF-токен обязателен для изменяющих операций. Токен обновляется при входе.
- Параметризованные SQL-запросы. Изменения выполняются в транзакции, UNIQUE защищает записи, прогресс, отзывы, сертификаты и избранное от дублей.
- Ограничение регистрации/входа: 15 запросов с одного IP за 15 минут; счётчики хранятся в базе. Заголовкам X-Forwarded-For приложение не доверяет.
- Учебные файлы отдаются после проверки записи и доступности урока. Чужие сертификаты, заметки, попытки и прогресс не выдаются.
- Загрузка до 8 МБ, HTTP-запрос до 10 МБ. Изображения: JPG/PNG/WebP до 16 мегапикселей, декодирование и повторное сохранение в JPEG. Материалы: также PDF, UTF-8 TXT/CSV. Имена на диске случайные, PDF и текст выдаются вложениями.
- Обложки и аватары публичны. SVG принимаются только как встроенные иллюстрации из исходного проекта; загружать SVG нельзя.
- Разрешённые iframe: `https://www.youtube-nocookie.com/embed/ID`, `https://rutube.ru/play/embed/ID/`. Приложение не загружает произвольные URL сервером.
- CSP, X-Frame-Options, nosniff, запрет кеширования API. Ошибки пользователю не раскрывают внутренний traceback.
- Важные административные операции пишутся в журнал. Последний активный администратор защищён от блокировки.

В production задайте собственный `SECRET_KEY`, HTTPS и `COOKIE_SECURE=1`; запускайте Waitress за настроенным HTTPS reverse proxy. SQLite и `instance/uploads` требуют резервного копирования вместе. Не публикуйте `.env`, `instance`, `.venv` и файлы локального доступа.

## Конфигурация

| Переменная | Назначение |
| --- | --- |
| SECRET_KEY | Случайный секрет подписи сессий; без него HTTP отвечает 503 |
| DATABASE | Путь к SQLite, по умолчанию instance/platform.sqlite3 |
| COOKIE_SECURE | 1 при HTTPS, 0 для локального HTTP |
| PDF_FONT | Путь к TTF с кириллицей; автоматически Arial в Windows или DejaVu Sans в Linux |
| PUBLIC_URL | Необязательный публичный адрес сайта для ссылок проверки сертификатов в QR-кодах; например, `https://example.org` |

## Известные ограничения

- Это готовое локальное приложение для небольших учебных групп, не проверенный нагрузочными испытаниями многопользовательский SaaS. SQLite сериализует записи; каталог и административные списки пока не оптимизированы для десятков тысяч записей.
- Внешние видео не сохраняют временную позицию; последний доступный урок сохраняется. Воспроизведение зависит от доступности разрешённого провайдера.
- Форматированный контент редактируется как безопасный HTML, без визуального WYSIWYG-редактора. Изображения добавляются материалами урока.
- Нет внешних интеграций, оплаты, чата, подтверждения email и восстановления пароля по email. Их не требует основной сценарий.
- Файлы проверяются по типу и содержимому, но не сканируются антивирусом. Неиспользуемые загруженные файлы автоматически не удаляются с диска.
- Журнал показывает последние 300 действий, кабинет — последние 100 событий и уведомлений; полная история остаётся в базе.
- Полная кроссбраузерная, нагрузочная и screen-reader сертификация не проводилась.
