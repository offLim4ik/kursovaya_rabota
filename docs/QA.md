# Проверка качества — 19 октября 2026

## Автоматические проверки

13 интеграционных тестов в `tests/test_platform.py` проходят. Каждый тест использует отдельную временную SQLite-базу. Проверены:

1. Регистрация обычного пользователя независимо от поля role, вход, сессия, смена пароля с проверкой текущего.
2. CSRF, отказ в административных API обычному пользователю, неизвестный аккаунт.
3. Запрет публикации пустого курса и очистка опасного HTML.
4. Запрет теста без вопросов и правильных ответов.
5. Полный сценарий: запись без дублей, последовательность, открытие без завершения, заметка, идемпотентность, повторный вход, серверная оценка, завершение, PDF, отзыв и изоляция данных.
6. Блокировка существующей сессии, разблокировка, защита последнего администратора.
7. Архивирование с сохранением доступа, защита состава программы, переименование и перестановка.
8. Защита учебного файла от гостя и недоступного урока; загрузка аватара и отказ на поддельное изображение.
9. Ограничение частоты входа.
10. Повторный запуск миграций, полноценное заполнение демонстрации, отказ повторного заполнения.
11. Публичный каталог, поиск кириллицей без учёта регистра, фильтры, неверный номер страницы, отзыв до завершения.
12. Приватность истории тестовых попыток.
13. Запрет подстановки идентификаторов уроков другого курса в редактор.
14. Проверка режима свободного прохождения после записи.

Команды: `python -m pytest -q`, `python -m ruff check .`, `python -m mypy`, `node --check static/app.js`.

Ruff: без ошибок. Mypy: без ошибок в 8 Python-файлах приложения; режим check_untyped_defs, не strict. JavaScript: синтаксическая проверка Node без ошибок; TypeScript в проекте не используется.

Production-пакет создаёт `python scripts/build.py`: компиляция Python, архив исходников, SHA-256 manifest и полный текст исходников. Frontend buildless, отдельного npm build нет.

## Реальный запуск и ручная проверка

Приложение запущено через Waitress на локальном HTTP. Во встроенном браузере проверены:

- Каталог с 6 курсами, обложки, фильтры и русскоязычные подписи.
- Форма входа и вход демонстрационного пользователя.
- Кабинет с реальными записями и прогрессом.
- Восстановление доступного урока, сохранение заметки и завершение урока.
- Обновление прогресса с 17% до 33% и открытие следующего урока.
- Выход, вход администратора, список курсов, редактор, предпросмотр и обзор с данными базы.
- Визуально просмотрены узкая панель около 600 px и широкая около 1265 px. Полная эмуляция всех мобильных устройств не проводилась.
- PDF с кириллицей сгенерирован ReportLab, отрисован Poppler и визуально проверен: имя, название, дата и номер читаемы, текст не обрезан.

Формы имеют подписи, фокус клавиатуры видим, статусы не зависят только от цвета. Пустые списки, ошибки API, loading и toast реализованы. Это не заменяет формальный аудит WCAG или проверку настоящим screen reader.

## Ограничения проверки

Первый запуск Pytest внутри Windows-песочницы не смог создать временные каталоги. Тесты повторно запущены с разрешением вне песочницы и прошли. Аналогично локальный сервер потребовал разрешения на открытие сокета.

Не проводились нагрузочные испытания, полноценный внешний пентест, проверка во всех браузерах и проверка реального воспроизведения каждого внешнего видеопровайдера. Производительность для больших каталогов не заявляется.
